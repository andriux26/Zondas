Zondas ESP32 Web Flasher

Prijunk TTGO LoRa32 V2.1 prie USB ir paspausk mygtuką. Bus įrašyta visa 4 MB atminties struktūra: bootloader, programinė įranga, šriftai ir LittleFS duomenys.

Ši naršyklė nepalaiko Web Serial. Naudok Chrome arba Edge.

Kompiuteryje naudok Chrome arba Edge. Android telefone reikia Chrome ir USB OTG. Įrašymo metu neatjunk USB.

OTA failai: update.ino.bin ir update.fs.bin.
